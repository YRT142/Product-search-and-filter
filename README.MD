# Simple Online Store

A lightweight, responsive single-page web app built to help customers quickly find and filter store products.

## Features
- **Product Catalog:** Stores 8 initial items across Electronics, Stationery, and Fashion.
- **Two-Column Grid:** Clean layout showing item name, category tag, and price.
- **Live Search Bar:** Real-time text filter that filters products by name (case-insensitive).
- **Category Dropdown:** Lets users filter by specific categories (`ALL`, `ELECTRONICS`, `STATIONERY`, `FASHION`), working seamlessly alongside the search input.
- **Dynamic Counters:** Displays "Showing X of Y products" or a "No products found" state dynamically.
